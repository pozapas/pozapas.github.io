System 1 Models in Safety Research: What Jev and Laya Can and Cannot Do
Guest lecture, CE 7393, Texas State University, 14 October 2026
Amir Rafe, Ph.D., AIT Lab, Ingram School of Engineering

TO VIEW OR PRESENT
Double-click index.html. It opens in any modern browser and needs no internet
and no installation. Online copy: https://pozapas.github.io/talks/system1-safety/

KEYS
Right arrow or Space   next step
Left arrow             previous step
F                      full screen
S                      speaker view with notes and timer (allow pop-ups if asked)
T                      start the countdown on a prediction sheet
Esc or O               overview of all sheets

LIVE MODEL RUNS (optional)
The live sheets show answers recorded on 10 October 2026 when no runner is
available. To run new questions live on your own computer:
    pip install laya==0.4.2 typesafe-sdk
    python runner/server.py
Laya runs locally with no key. Jev needs a TypeSafe API key in the
TYPESAFE_API_KEY environment variable. Then open index.html through a local
server (python -m http.server 8790, then http://127.0.0.1:8790).
