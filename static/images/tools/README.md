# Tool screenshots

Put replacement tool screenshots in this folder:

`static/images/tools/`

Use a 16:9 image. A size of 1280 x 720 pixels is preferred. WebP is preferred because it keeps the page small.

## Replace an existing screenshot

1. Export or capture the tool at 1280 x 720 pixels.
2. Convert the image to WebP when possible.
3. Give the image the same file name as the image that you want to replace.
4. Replace the existing file in this folder.
5. Reload the local site with `Ctrl+Shift+R`.

The tool records and image paths are in `data/tools.yml`.
